# Clipboard Copy Skill

このSkillは、ユーザーのMac環境の `pbcopy` コマンドを使用して、AIエージェントの直前の出力や特定のテキスト、コードスニペットをクリップボードにコピーするためのものです。
エスケープなどの問題を避けるため、必ず同梱のヘルパースクリプトを使用してください。

## 使い方

ユーザーからクリップボードへのコピーを求められた場合、以下の手順に従います。

1. **コピー対象の特定**: ユーザーの指示から、何をコピーすべきかを正確に特定します。
    - 全文コピーの場合: 直前の出力をそのままコピーします。
    - 部分コピーの場合: 「HTML部分だけ」「`handleSubmit` 関数だけ」「箇条書きにして」などの任意の指示に従い、テキストを抽出・加工します。
2. **スクリプトの実行**: 利用可能なシェル実行ツールを使用して、抽出したテキストを同梱のスクリプト（`copy.py`, `copy.sh`, `copy.js` のいずれか環境に合うもの）に渡します。

*注意: スクリプトのパスは、このSkillディレクトリ（`SKILL.md` が配置されているディレクトリ）からのパスとして解決するか、環境に応じて適切にパスを取得して指定してください。*

3. **完了報告**: コピーが完了したことをユーザーに簡潔に伝えます。

## コマンド実行のベストプラクティス

安全にクリップボードにコピーするため、ヒアドキュメントを用いてスクリプトの標準入力にテキストを渡してください。
（変数の展開を防ぐため、必ず `EOF` をシングルクォートで囲みます。）

### Pythonを使用する場合
```bash
cat << 'EOF' | python <skill-dir-path>/scripts/copy.py
ここにコピーしたいテキストや
コードスニペットを配置します。
EOF
```

### Bashを使用する場合
```bash
cat << 'EOF' | bash <skill-dir-path>/scripts/copy.sh
ここにコピーしたいテキスト
EOF
```

### Node.jsを使用する場合
```bash
cat << 'EOF' | node <skill-dir-path>/scripts/copy.js
ここにコピーしたいテキスト
EOF
```

テキストが非常に長い場合や、`EOF` という文字自体が含まれる場合は、予測可能でセキュアでない `/tmp/` 以下の固定ファイル名ではなく、`mktemp` を用いてパーミッション（0600）を絞った一時ファイルを作成し、引数としてスクリプトに渡してから確実に削除してください。

```bash
TMP_FILE=$(mktemp)
chmod 600 "$TMP_FILE"
cat << 'EOF' > "$TMP_FILE"
ここにコピーしたいテキスト...
EOF
python <skill-dir-path>/scripts/copy.py "$TMP_FILE"
rm -f "$TMP_FILE"
```

## 部分コピー（任意の指示）への対応

ユーザーは「直前の出力の〇〇だけコピーして」と任意の指示をしてくることがあります。
その際は、ユーザーの意図を汲み取り、テキストを適切に抽出・整形した上で上記のスクリプトに渡してください。
（例：特定の関数だけを抜き出す、指定されたフォーマットに変換してからコピーするなど）
